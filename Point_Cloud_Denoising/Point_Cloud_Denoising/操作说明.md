# 操作说明

## 文件清单
```
PointCloud/
├── calculator.py     ← 核心算法（统计滤波去噪）
├── file_io.py        ← 文件读写
├── main_window.ui    ← Qt Designer 界面
├── main_window_ui.py ← PyUIC 生成（见第2步）
└── app.py            ← 主程序，运行这个
```

---

## 启动步骤

### 第1步：生成 UI 文件
在 PyCharm 终端执行：
```bash
python -m PyQt5.uic.pyuic main_window.ui -o main_window_ui.py
```

### 第2步：运行
```bash
python app.py
```

---

## 使用流程
```
打开（Ctrl+O）→ 选择 point.txt
      ↓
运行去噪（F5）→ 后台计算（44518个点约需数秒）
      ↓         左侧表格显示29项结果
                右侧显示统计摘要报告
      ↓
保存（Ctrl+S）→ 生成 result.txt
```

---

## 算法流程说明
```
1. 读入点云（44518点）
2. 格网划分（边长=3m，划分三维网格）
3. k邻近搜索（k=6，遍历27个相邻网格）
4. 统计特征（每点邻域平均距离 uᵢ 和标准差 σᵢ）
5. 全局统计（所有点 uᵢ 的均值μ和标准差σ）
6. 噪声判断（uᵢ > μ + 2σ → 噪声点）
```

---

## 注意
- 计算量较大（44518点×27邻域），界面用后台线程，不会卡死
- 进度条转动时请耐心等待（约5-30秒，取决于电脑性能）
