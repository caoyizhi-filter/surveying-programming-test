# 操作说明

## 文件清单
```
Error_Ellipse/
├── calculator.py       ← 计算公式（不用改）
├── file_io.py          ← 文件读写（不用改）
├── draw_widget.py      ← 绘图控件（不用改）
├── main_window.ui      ← Qt Designer 界面文件
├── main_window_ui.py   ← PyUIC 生成（见第2步）
└── app.py              ← 主程序，运行这个
```

---

## 第1步：把所有文件放到同一文件夹

把下载的5个文件全部放到 `Error_Ellipse/` 目录下（平铺，不要建子文件夹）

---

## 第2步：生成 main_window_ui.py

在 PyCharm 终端执行：

```bash
python -m PyQt5.uic.pyuic main_window.ui -o main_window_ui.py
```

执行后目录里会出现 `main_window_ui.py`，不要手动修改它。

---

## 第3步：安装依赖

```bash
pip install PyQt5
```

---

## 第4步：运行

右键 `app.py` → Run 'app'

或终端：
```bash
python app.py
```

---

## 使用流程

```
打开（Ctrl+O）→ 选择 ellipse.txt
      ↓
计算（F5）    → 结果填入左侧表格
      ↓
绘图（F6）    → 右侧显示椭圆
      ↓
保存（Ctrl+S）→ 生成 ellipse_result.txt
```
